MEXC SWING ENGINE V11 — BACKTEST / DEPLOYMENT NOTES

Authoritative strategy timeframes:
- 1D
- 12H
- 4H
- 1H

12H is causally synthesized from three contiguous completed 4H candles.
The only execution baseline is market entry at the next 1H open after the completed reclaim candle.

Supported paper backtests:
- 1D
- 7D
- 30D
- 60D
- 90D
- 180D
- 365D

Use 1D/7D for smoke tests, 30D/90D+ for statistical evaluation, and 180D/365D for robustness. A true walk-forward study still requires explicit train/test segmentation outside this simple fixed-window runner.

The backtest never calls the live executor and never places a real order. Historical execution uses the next 1H open with fee/slippage modeling plus the same fixed funding allowance used by live signal validation.

Important research limitation: the universe is the current eligible MEXC universe, not a survivorship-bias-free historical universe. Live order-book, spread, freshness, and funding history cannot be reconstructed exactly from ordinary OHLCV; V11 therefore uses a conservative fixed cost/funding allowance for historical acceptance.

Deployment safety:
- SCANNER_ENABLED=false by default
- AUTO_SIGNAL_ENABLED=false by default
- AUTO_TRADE_ENABLED=false by default
- ALLOW_LIVE_EXECUTION=false by default

Do not enable live trading until the V11 execution adapter has been separately validated against real MEXC responses and actual-fill reconciliation.
