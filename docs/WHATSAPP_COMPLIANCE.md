# WhatsApp compliance status — blocked

Meta's current WhatsApp Business Messaging Policy includes real, virtual or fake currency and prohibits buying/selling, promoting or facilitating exchange of those assets. Crypto-futures trade signals are not enabled by this app. The `WhatsAppSignalAdapter` is deliberately hard-blocked and contains no sending code; setting environment variables cannot activate it.

Do not attempt to evade policy by changing message wording, using an unofficial WhatsApp Web automation client, a different business identity, or misleading templates. Use the authenticated dashboard's in-app signal feed. Reassess only if Meta publishes a policy change and provides explicit written approval for this exact application/use case; a generic API account or template approval is not that permission.
