FIXES APPLIED
1. Run-level V11 configuration diagnostics are recorded once, not summed across symbols. Counterfactual TP distance is also recorded once.
2. TP counterfactuals simulate CONTROL first. Per-symbol cooldown and cross-symbol portfolio acceptance use CONTROL exits, preserving signal/candidate populations while only the exit outcome is counterfactual.
3. Backtest windows can be frozen through V11_BACKTEST_START_MS / V11_BACKTEST_END_MS environment variables, BACKTEST_START_MS / BACKTEST_END_MS settings, or BacktestRunner.run(start_ms=..., end_ms=...). Reports include exact millisecond values.
4. V11_BACKTEST_SYMBOLS lets comparison runs use a fixed comma-separated symbol set instead of a changing current-universe snapshot.
5. 1D bull/bear votes are symmetric and ADX no longer grants an undirected vote to both sides; active directional structure/momentum is required.
6. 1H triggers must reclaim on the current decision candle. Trigger body/close-location quality, swept-level extension (0.85 ATR(1H)), and impulse value corridor are enforced. Weak historical reclaims no longer mask a valid current-bar reclaim.
7. Target selection checks confirmed 1H/4H/12H/1D structure and impulse-relative levels. A candidate must clear the post-cost RR floor within 2.50R; the engine does not invent a synthetic target to force that cap.
8. Backtest positions are filtered chronologically using configured maximum open positions, same-direction count, and total planned risk. Acceptance uses CONTROL exits across all TP modes.
9. Scanner and backtest pass the same effective round-trip cost estimate into the analysis engine, and the paper simulator's default fee matches Settings.
